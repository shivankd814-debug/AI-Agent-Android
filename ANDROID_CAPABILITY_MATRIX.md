# Android capability matrix

| Capability | Status in this starter | Notes |
|---|---|---|
| Voice recognition | Implemented starter UI | Uses Android speech recognition intent |
| Text-to-speech | Implemented | Hindi locale requested; device may fallback |
| Backend command execution | Not wired | Requires authenticated API integration |
| Notification reading | Service skeleton | User enables access; privacy filters required |
| Accessibility UI actions | Service skeleton | Narrow, user-approved actions only |
| Phone calls | Not implemented | Default dialer/role and Android restrictions apply |
| SMS send/read | Not implemented | Default SMS role and policy constraints apply |
| WhatsApp/Instagram DM | Not implemented | Prefer official APIs; UI automation may be restricted |
| Reel publishing | Not implemented | Official platform publishing API eligibility applies |
| Always-on wake word | Not implemented | Background microphone restrictions and battery impact |
